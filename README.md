# CSharp Calculator

> A terminal application that evaluates mathematical expressions

## About

Application for evaluating mathematical expressions written in C#. Supports:

- **Parentheses** - ()
- **Addition** - +
- **Subtraction** - -
- **Multiplication** - *
- **Division** - /

## Getting started

1. Clone into the repository:

    ``` bash
    git clone https://github.com/DavidDevKing/CSharpCalculator
    cd CSharpCalculator
    ```

2. Run the application:

    ``` bash
    dotnet run
    ```
